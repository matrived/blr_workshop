OpenClaw on AMD Instinct MI300X — Quick Start

Launch a vGPU-sliced Jupyter notebook (47 GB VRAM) and run the OpenClaw AI agent

1Join WiFi

Connect to the
"AMD Guest"
wireless network

You must be on this network to access the notebooks platform.

➔
2Sign In

Go to:

https://notebooks.amd.com/nb-testing

Click on "Trouble signing in?"

Enter your email and the passcode as password:

AMDNBTesting

This logs you in and unlocks the gallery in one step.

➔
3Launch OpenClaw

In the gallery, click the card:

Slicing Test — OpenClaw

Tags: GPU MI300X vGPU VRAM Slicing OpenClaw

Click Request Notebook. Wait for JupyterLab to open.

4Run the Setup Cell (few min)

Open openclaw.ipynb from the file browser. Click the first code cell, then:

• Click ▶ Play in the toolbar,  or  press Shift+Enter

Cell turns yellow while running — please wait. When it succeeds it turns green. Do not proceed until green.

If the cell turns red (error), stop here — do not continue with Step 5.
Report the issue with your email address to the presenter.

➔~1-2 min
5Chat with OpenClaw (in the notebook)

Run the next cell to open the embedded chat widget — no terminal needed!

A chat box appears with a text input and Send button. Type Hi and press Enter to say hello.

Then run the "Clone & Analyze" cell — it clones a repo and sends this prompt:

Clone https://github.com/matrived/blr_workshop.git in /workspace directory, show me the repository structure line-by-line one-liner description of them and also describe cell-by-cell what unsloth-finetuning/grpo_game2048-finetune-unsloth/gpt_oss_20B_Reinforcement_Learning_2048_Game_BF16.ipynb file is doing in each cell in 1 line and lastly what could be improved

Keep chatting — ask anything! All in-notebook via Shift+Enter.
